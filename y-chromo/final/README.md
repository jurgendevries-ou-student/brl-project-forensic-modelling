# README

## Project

This project was developed as part of the course **Bayesian Reasoning and Learning (IM0902)**. It contains the experiments and report on applying Bayesian networks to forensic investigations involving Y-chromosomal DNA profile matching.

## Contents

- `report.pdf` – Final report.
- `experiments.ipynb` – Jupyter notebook used for modelling, inference, structure learning, and classification.
- `experiments.html` - Export of Jupyter notebook.
- `requirements.txt` - Required dependencies used to run the Jupyter notebook. 



## Requirements

The project was developed in Python using, among others:

- pyAgrum
- pandas
- scikit-learn
- matplotlib
- graphviz

The requirements.txt is included.

## Use of Generative AI

Generative AI was used as a supporting tool during this project. Specifically, it was used for:

- assisting with debugging Python and pyagrum code;
- suggesting improvements to the wording and flow of the report;
- acting as a sparring partner during the initial phase of the project to help define and refine its scope.

All modelling decisions, implementation, experiments, interpretation of the results, and the final report are my own work and inspired by the found literature. AI-generated suggestions were critically evaluated and adapted (or ignored) where appropriate.
